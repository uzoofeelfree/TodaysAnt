# 🐜 TodaysAnt

프리랜서를 위한 작업시간·수익 관리 PWA입니다.

## GitHub Pages 배포

1. 이 폴더 안의 파일과 폴더를 저장소 최상위에 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
5. 잠시 후 표시되는 Pages 주소로 접속합니다.

## 설치

- PC/Android Chrome: 주소창의 설치 아이콘 또는 앱 안의 설치 버튼
- iPhone Safari: 공유 → 홈 화면에 추가

## 데이터 저장

현재 데이터는 각 브라우저의 `localStorage`에 저장됩니다. 기기 간 동기화와 로그인 기능은 아직 포함되지 않았습니다.
