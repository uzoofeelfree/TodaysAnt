TodaysAnt — GitHub Pages 업로드용 PWA

1. GitHub에서 새 저장소 이름을 TodaysAnt로 만듭니다.
2. 이 압축 파일을 푼 뒤, 안의 파일과 폴더를 저장소 최상위(root)에 모두 올립니다.
3. GitHub 저장소에서 Settings → Pages로 이동합니다.
4. Source를 Deploy from a branch로 선택합니다.
5. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
6. 잠시 뒤 표시되는 GitHub Pages 주소로 접속합니다.

설치 방법
- PC / Android Chrome: 화면의 “TodaysAnt 설치” 버튼 또는 주소창의 설치 아이콘
- iPhone Safari: 공유 버튼 → 홈 화면에 추가 → 웹 앱으로 열기

중요
- TodaysAnt는 기존 TodayAnt와 별도의 새 저장 공간을 사용합니다.
- 현재 데이터는 각 기기의 브라우저에 저장됩니다. PC와 모바일 데이터는 아직 자동 동기화되지 않습니다.
- 브라우저 사이트 데이터를 삭제하면 기록도 지워질 수 있습니다.
